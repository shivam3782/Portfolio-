# Redesign change log

- Rebuilt the public portfolio as a responsive retro console interface with charcoal/orange/teal themes, self-hosted Silkscreen and Space Grotesk fonts, CSS 3D scene, five cartridge project cards, case-study routes, gallery/lightbox, mobile menu, accessible command palette, contact form, 404 and error recovery.
- Preserved project CRUD, authentication, existing data and `/admin`. Added a Profile singleton, private contact inbox, and project case-study fields (`status`, `problem`, `solution`, `role`, `features`, `architecture`, `challenges`, `learning`, `screenshots[{url,alt}]`). All additions default safely; no migration changes existing records. API additions: `GET/PUT /api/profile`, `POST /api/contact`, `GET /api/messages`, optional `POST /api/events/resume`. Existing API contracts remain valid.
- Public content uses CMS data with a verified bundled snapshot and local last-known-good cache. Static HTML for home, five projects and 404 contains crawler-visible copy, route metadata and JSON-LD. Added OG image, favicons, manifest, sitemap and robots. `SNAPSHOT_API_URL` refreshes static content from CMS during builds.
- Added Helmet, contact/auth rate limits, strict input validation, request-size limit, safe URL checks and optional anonymous aggregate analytics. Removed unused motion, Lenis and Tailwind packages. Removed tracked local `.env` files from Git; local overrides remain ignored.
- New public env vars: `VITE_SITE_URL`, `VITE_API_URL`, `VITE_ANALYTICS_ENABLED`; build-only `SNAPSHOT_API_URL`, local `API_PROXY_TARGET`. New backend vars: `TRUST_PROXY_HOPS`, `ANALYTICS_ENABLED`; existing `MONGO_URI`, `ADMIN_KEY`, `CORS_ORIGINS`, `PORT`, `NODE_ENV` remain.
- Project images and demo links remain absent where none were supplied. CMS prompts the owner to add real screenshots and case-study depth.
